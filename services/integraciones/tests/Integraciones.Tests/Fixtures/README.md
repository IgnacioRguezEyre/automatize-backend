# Correos de ejemplo

Cuerpos de alertas reales de cada portal, **anonimizados**: sin nombre ni dirección del destinatario,
sin tokens de seguimiento y con los enlaces de oferta reducidos a lo imprescindible (el id).
Se usan para probar los analizadores contra el formato que mandan de verdad los portales.

Si un portal cambia el formato, guarda aquí un correo nuevo (anonimizado) y añade su test.
